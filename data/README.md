# Data

The raw LUCAS 2018 topsoil files are **not included** in this repository
(they are distributed by the European Soil Data Centre, ESDAC, under their own terms).

Download them from ESDAC (https://esdac.jrc.ec.europa.eu/projects/lucas) and place them here:

- `LUCAS-SOIL-2018.csv`
- `BulkDensity_2018_final-2.csv`
- `LUCAS_Text_All_10032025.csv`
